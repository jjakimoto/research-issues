Dependence-Informed Sparse Neural Architecture for Stock Return Prediction

📰 Latest · 2026-08-24 Full Article
Read full article →

Topic: Quantitative trading; machine learning for quant & trading; agentic coding techniques; LLMs & multimodal LLMs; and autonomous research (autoresearch / AI-scientist) systems — methods, papers, tools
Date: 2026-08-24

Source: arxiv · 2026-08-14
Link: https://arxiv.org/abs/2608.14323

Instead of grid-searching depth and width, this paper reads a network's entire topology off a Maximally Filtered Clique Forest over firm-characteristic correlations — matching a dense NN3 benchmark's ranking power with roughly 80x fewer parameters and giving every hidden unit a named subset of characteristics. The asset-weighted, cost-adjusted results, however, partly reverse the advantage.

Executive summary

The authors build a Homological Neural Network whose depth, layer widths, and sparse connections come directly from a Maximally Filtered Clique Forest (MFCF) fit to the absolute-correlation structure of 94 firm characteristics, rather than from cross-validated hyperparameter search. On a 1987-2016 walk-forward U.S. equity panel, two HNN variants match or slightly beat a fully connected NN3 benchmark on rank-based accuracy while using about 80x fewer parameters than an equivalently-sized dense network, and ablations show both the sparsity and the specific estimated clique grouping contribute. The gains are modest, partly non-significant before multiple-testing correction, and partly reverse once asset-weighting and transaction costs are applied.

Problem: architecture choice is disconnected from financial structure

Standard neural return-prediction models (the Gu-Kelly-Xiu NN3 dense MLP) fix depth and hidden width by cross-validated grid search, which is hard to tie back to any financial interpretation of what a hidden unit represents.

  • Motivation: derive architecture from an estimated dependence structure among characteristics instead of hyperparameter search.
  • Goal: make each hidden unit correspond to an explicit, named subset of characteristics.

Method: from a clique forest to a Homological Neural Network

The dependence graph D_ab = |corr(X_a, X_b)| is computed on rank-transformed characteristics; an MFCF groups characteristics into nested maximal cliques, attaching new nodes via an admissible separator S with gain G(v,S) = sum over u in S of D_vu^2, subject to clique size |C| <= K. K, the maximum clique size, is the only parameter controlling architectural complexity — it bounds how many characteristics sit in each maximal clique and hence the highest interaction order the network can represent.

  • Layer k has one unit per distinct order-k subset present in some maximal clique; connections follow inclusion, so a unit only receives input from its size-(k-1) subset units.
  • Activation h^(k) = ReLU(LayerNorm[W^(k) h^(k-1) + b^(k)]), with W^(k) trainable only for subset-superset pairs.
  • Readout: each non-input layer is summarised into a scalar r^(k); prediction is a linear combination of those plus an intercept, targeting next-month excess return.
  • Sparse vs dense parameter counts are compared directly: P_sparse = sum(k * n_k) versus P_dense = sum(n_{k-1} * n_k) for a fully connected net of the same induced widths.
  • Ablations: HNN (marginal) builds one dependence graph from all training data (ignoring returns); HNN (m-s) unions clique sets from a median split on training excess return; HNN (input-shuffled) permutes which characteristic feeds which input node while holding topology fixed; MLP-HNN keeps the same widths but connects them densely.

Data and walk-forward evaluation protocol

The panel is the standard GKX-style U.S. equity dataset: 94 firm characteristics, monthly returns from 1957-2016, cross-sectionally rank-transformed to [-1,1] each month with missing values set to 0 (a near-zero-variance screen leaves 90-94 usable characteristics per window).

  • Expanding training window, 12-year validation window, 1-year test window, refit each year; total out-of-sample sample is 2,508,749 observations.
  • Training: Adam, MSE loss, batch size 10,000, up to 100 epochs, gradient clipping at 1, early stopping (10 epochs for HNN, 5 for dense benchmarks), 10-seed ensembles.
  • Hyperparameter grids: learning rate in {1e-4, 1e-3, 3e-3, 1e-2, 3e-2}; K in {2,...,7}; L1 penalty in {1e-6, 1e-5, 1e-3}; Huber epsilon in {1.1, 1.35, 1.5, 2.0}; PCR components in {5,10,20,30,40,60,80,94}.
  • Baselines: Huber-3 (regularised linear), PCR, and NN3 (dense 3-hidden-layer MLP).
  • Inference uses pairwise Diebold-Mariano tests with Newey-West HAC standard errors (6 lags) and a Holm correction across 18 p-values.

Results: matching NN3 with far fewer parameters, with caveats

HNN (marginal) attains the best Pearson IC (0.0642) of all models, edging NN3's 0.0586 with a Holm-adjusted p=0.034, while pooled out-of-sample R-squared differences versus NN3 are not significant (p=0.796). Against MLP-HNN (same widths, dense), HNN (marginal) uses about 21.0k parameters versus 1,680.7k — roughly 80x fewer — while keeping a significant Pearson IC edge after Holm correction (p=0.001). The input-shuffle ablation drops Pearson IC from 0.0642 to 0.0597 (adjusted p=0.003), indicating the specific estimated grouping, not just sparsity, matters.

  • Cost and turnover results (359 rebalances) are more mixed: asset-weighted at 25bps, HNN (marginal)'s net return and Sharpe trail NN3's (1.31% vs 1.78% net; p=0.036 favouring NN3), even though equal-weighted results favour HNN.
  • Decade breakdown: HNN beats NN3 on both R-squared and Pearson IC in 19 of 30 test years; in 2007-2016 both turn negative (-0.135 vs -0.138), though HNN (m-s) is the best neural model in that decade.
  • Decile spread for HNN (marginal): bottom decile -0.97%, top decile 2.98%.

Significance

The contribution is a way to fix a network's entire topology from an estimated dependence graph rather than searching depth and width, giving each hidden unit a literal characteristic-subset interpretation — a property the dense benchmarks lack. Both ablations point to sparsity AND the specific estimated grouping as separate contributors.

  • Central empirical claim: comparable-to-slightly-better ranking accuracy at ~80x fewer parameters than an equivalent dense network.
  • Sits naturally alongside the correlation-filtering/clustering line of financial-ML methodology (filtered graphs, denoising, hierarchical structure).

Key findings

  • HNN (marginal) achieves the top Pearson IC (0.0642) versus NN3's 0.0586, a Holm-adjusted significant edge (p=0.034), while pooled R2_oos is statistically indistinguishable from NN3 (p=0.796).
  • HNN (marginal) uses about 21.0k parameters versus 1,680.7k for the same-width dense MLP-HNN — roughly 80x fewer — while keeping a significant Pearson IC advantage (Holm-adjusted p=0.001).
  • Randomising the characteristic-to-input-node mapping while holding topology fixed drops Pearson IC from 0.0642 to 0.0597 (adjusted p=0.003), showing the estimated clique grouping adds value beyond sparsity alone.
  • Asset-weighted, cost-adjusted results partly reverse the ranking advantage: at 25bps, HNN (marginal)'s net return and Sharpe (1.31% / 0.73) trail NN3's (1.78% / 0.95), p=0.036.
  • Performance is uneven across decades: HNN beats NN3 in 19 of 30 test years, but both post negative R-squared in 2007-2016 (-0.135 vs -0.138).
  • The walk-forward protocol spans 30 non-overlapping test years over 2,508,749 out-of-sample observations, with the correlation matrix re-estimated each window.

Notable quotes

Returns are not used, so the architecture depends only on the characteristics.
The first test year is 1987 and the last 2016, giving 30 non-overlapping test years.
The correlation matrix is computed from 150,000 training observations drawn at random in each window.
What the filtered graph contributes is therefore not only sparsity but also the particular clique structure it estimates.

Limitations

  • The cost- and asset-weighted picture partially reverses the headline advantage (p=0.036 favouring NN3), so the benefit concentrates in equal-weighted, smaller-cap-tilted portfolios.
  • Predictive performance collapses in the final decade (2007-2016), with both HNN and NN3 posting negative out-of-sample R-squared, raising doubts about more recent regimes.
  • The sample and the missing-value-as-zero / rank-transform pipeline mirror the standard GKX setup, so that panel's coverage limitations plus a simple linear transaction-cost model carry over.

Open questions

  • Would the dependence-informed sparsity advantage persist after 2016 or in non-U.S. equity markets, given the negative R-squared already seen in 2007-2016?
  • How sensitive is the clique structure, and downstream performance, to the dependence measure — absolute Pearson correlation versus mutual information or tail dependence?
  • Could the maximum clique size K be selected adaptively per clique rather than as one global hyperparameter, and would that close the equal-weighted vs asset-weighted gap?
