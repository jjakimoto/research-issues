Reflexion: Language Agents with Verbal Reinforcement Learning

📚 Foundations · 2026-09-04 Full Article
Read full article →

Topic: Quantitative trading; machine learning for quant & trading; agentic coding techniques; LLMs & multimodal LLMs; and autonomous research (autoresearch / AI-scientist) systems — methods, papers, tools
Date: 2026-09-04

Theme: Iterative self-correction for language agents
Reflexion and Self-Refine established two influential training-free patterns for improving agent behavior through natural-language feedback. Together they show that critique and revision can improve reasoning and code generation, but also that progress depends on grounded evaluators, reliable self-diagnosis, controlled memory, and safeguards against regressions.
Source: arxiv
Link: https://arxiv.org/abs/2303.11366

This paper is foundational for code and task agents because it turns execution feedback, failed trajectories, and tests into persistent verbal lessons that guide iterative self-correction without updating model weights.

Executive summary

Reflexion introduces a verbal-reinforcement framework in which an Actor attempts a task, an Evaluator scores the trajectory, and a Self-Reflection model converts sparse feedback into natural-language lessons stored in memory. Across embodied decision-making, multi-hop question answering, and code generation, these lessons improve subsequent attempts without gradient-based parameter updates. The programming experiments also show that reliable evaluators—especially generated tests—are essential because erroneous feedback can cause harmful revisions or premature acceptance.

Problem and motivation

Scalar rewards reveal whether an attempt succeeded but generally do not explain how an agent should improve. Reflexion addresses this credit-assignment problem by converting outcomes and trajectories into specific verbal feedback that an LLM can reuse on later trials.

  • The method targets sequential decision-making, reasoning, and programming tasks.
  • Learning occurs through language and persistent context rather than weight updates.
  • The framework seeks richer feedback than a binary success or failure signal.

Actor–Evaluator–Reflection loop

The framework separates execution from assessment and learning: an Actor generates actions or text, an Evaluator produces a task-specific score, and a Self-Reflection model writes a verbal experience based on the trajectory, reward, and existing memory. The Actor conditions later attempts on both the current trajectory and stored reflections; experiments usually retain only one to three reflections because of context-window limits.

  • Actors include Chain-of-Thought and ReAct agents.
  • Evaluators include exact-match grading, task heuristics, and LLM judgments.
  • Reflections identify mistakes, propose alternative actions, and become long-term memory.
  • The loop repeats until evaluation passes or the trial budget is exhausted.

Decision-making and reasoning results

On 134 ALFWorld tasks, ReAct plus Reflexion solved 130 tasks using a heuristic that triggers reflection after repeated actions or overly long trajectories. On HotPotQA, Reflexion improved both retrieval-oriented ReAct and reasoning-oriented Chain-of-Thought agents; with ground-truth context, it raised accuracy by 14%, while the episodic-memory ablation attributed an 8-point absolute advantage to explicit reflection beyond merely retaining the latest trajectory.

  • ALFWorld memory was truncated to the three latest reflections.
  • The ReAct-only ALFWorld agent converged with a reported 22% hallucination rate and no long-term recovery.
  • HotPotQA evaluation used exact-match feedback and a memory of three experiences.
  • Baseline agents did not recover failed first-trial tasks under the reported temperature-0.7 setup.

Programming method and benchmarks

For HumanEval, MBPP, and LeetcodeHardGym, the agent generated up to six candidate unit tests, filtered them for syntactic validity, executed them, and used failures to guide reflection and revision. Reflexion reached 91.0% pass@1 on HumanEval Python, 68.0% on HumanEval Rust, 75.4% on MBPP Rust, and 15.0% on Leetcode Hard Python, although it underperformed GPT-4 on MBPP Python because generated tests produced many false positives.

  • The method was tested for both interpreted Python and compiled Rust code.
  • HumanEval Python improved from the reported GPT-4 result of 80.1% to 91.0%.
  • MBPP Python fell from the reported GPT-4 result of 80.1% to 77.1%.
  • Generated-test false-positive rates were 1.4% for HumanEval Python and 16.3% for MBPP Python.

Ablation and significance for coding agents

On the 50 hardest HumanEval problems translated to Rust, the full combination of test generation and verbal reflection achieved 68% pass@1 versus a 60% base model. Omitting reflection left performance at 60%, while reflecting without test generation reduced it to 52%, showing that useful self-correction depends on both grounded feedback and an explicit diagnosis step.

  • Test execution can expose syntax and logic errors but does not by itself ensure that revisions address them.
  • Ungrounded reflection may force unnecessary, harmful edits to already-correct code.
  • The results motivate coding-agent architectures that preserve concise failure lessons across attempts.
  • Verbal reinforcement offers a more inspectable optimization trace than opaque parameter updates.

Key findings

  • Verbal reflections stored in memory let agents improve across trials without gradient-based model updates.
  • Reflexion solved 130 of 134 ALFWorld tasks with a heuristic evaluator and short reflection memory.
  • Explicit self-reflection provided an 8-percentage-point absolute gain over episodic-memory-only refinement in the HotPotQA reasoning ablation.
  • The full coding loop reached 91.0% pass@1 on HumanEval Python and 68% on the hardest HumanEval Rust subset.
  • Evaluator quality is a binding constraint: MBPP Python's 16.3% generated-test false-positive rate coincided with Reflexion underperforming the base GPT-4 result.

Notable quotes

This iterative process of trial, error, self-reflection, and persisting memory enables the agent to rapidly improve its decision-making ability in various environments by utilizing informative feedback signals.
ReAct + Reflexion significantly outperforms ReAct by completing 130 out of 134 tasks using the simple heuristic to detect hallucinations and inefficient planning.
These empirical results suggest that several recent works that propose blind trial and error debugging techniques without self-reflection are ineffective on harder tasks such as writing complex programs in Rust.
At its core, Reflexion is an optimization technique that uses natural language to do policy optimization.

Limitations

  • Natural-language policy optimization can still converge to non-optimal local minima.
  • Experiments restrict long-term memory to a small sliding window, usually one to three experiences, because of context limits.
  • Test-driven code evaluation is unreliable for nondeterministic or impure functions, hardware-dependent outputs, API interactions, and parallel or concurrent behavior.

Open questions

  • Can structured retrieval over vector or SQL-backed reflection memories outperform the paper's small sliding window without introducing irrelevant or contradictory lessons?
  • How can code agents detect and correct evaluator errors, especially generated-test false positives that cause invalid solutions to be accepted?
  • What monitoring and safety mechanisms are needed when verbal self-improvement is applied to agents operating external tools, software, or robotics?
