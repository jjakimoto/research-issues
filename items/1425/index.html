Omni Interaction Agent Technical Report

📰 Latest · 2026-09-10 Full Article
Read full article →

Topic: Quantitative trading; machine learning for quant & trading; agentic coding techniques; LLMs & multimodal LLMs; and autonomous research (autoresearch / AI-scientist) systems — methods, papers, tools
Date: 2026-09-10

Source: huggingface-daily-papers · 2026-09-08
Link: https://arxiv.org/abs/2609.08977

Tencent Hunyuan Speech's Gander is a 9B end-to-end omni interaction agent that splits realtime full-duplex perception/speech (a streaming Thinker-Talker "front cerebellum") from long-horizon agentic work (a training-free Codex/Claude-Code "back brain"). It wins turn-taking on Full-Duplex-Bench v3 (100% take-turn, 8.0% premature interruption) while honestly reporting that its end-to-end task accuracy trails every baseline (Pass@1 0.400) and that WorldSense regresses 6.08 points versus its MiniCPM-o 4.5 base.

Executive summary

Gander unifies streaming audio-visual perception, full-duplex speech interaction, and agentic task execution in one system. The front cerebellum is a thinker-talker omni model that flattens 1-second chunks of audio tokens, visual tokens, a control token (listen/speak/interrupt), and emitted text into a single causal stream with a 128-chunk (~2 min) sliding window; it delegates long-horizon work to a training-free back brain (default: Codex app server, driven by GPT-5.6) via task_start / task_send / task_resolve tool calls enforced by a gateway. Training uses a 2.7M-sample corpus including 260.8K synthesized full-duplex dialogues with explicitly annotated competitive interruptions and supportive backchannels. Evaluation is unusually candid: Gander is best-in-table on interaction timing but last-in-table on task accuracy end to end, and the paper attributes the gap to the training format and the speech path rather than the architecture.

Cerebellum-Brain collaborative framework

Three components: front cerebellum (realtime full-duplex omni model, task routing), agent orchestration runtime (coordination/gateway), and back brain (training-free general agent). Delegation is expressed as structured tool calls; the gateway binds them to the authenticated user turn so objectives are grounded in real user input, not model-invented tool parameters.

  • task_start creates a background task; task_send routes follow-ups in `main` (steer) or `fork` (read-only side query) mode; task_resolve gives cancel / allow_once / allow_session / deny
  • Runtime has two control modes: `lean` (direct, lower latency, deterministic) and `coordinator` (a separate control-plane model emitting a declarative plan, validated by the gateway)
  • Gateway manages five persistent entities — Project, Task, Run, WorkerEvent, Delivery — with workspace isolation and a unified Worker Provider interface
  • Back brain gets three runtime interfaces beyond its native tools: context_fetch, memory_search, share

Streaming Thinker-Talker architecture and chunk flattening

All modalities plus the model's own output are serialized into one causal stream partitioned into fixed 1-second windows. Each chunk = encoded audio+visual tokens for that window, one predicted control token, then N model-chosen text tokens (possibly zero). Context is a fixed 128-chunk sliding window (~2 minutes), keeping per-step cost stable over arbitrarily long sessions.

  • Control token is one of listen / speak / interrupt, predicted before any content — decoupling *whether* to speak from *what* to say
  • No external VAD: the once-per-window decision also yields proactive behavior
  • Vision: any-resolution slicing + SigLIP + query-based resampler giving ~16x token reduction (vs ~4x in prior omni models), frames up to 448x448
  • Audio: streaming ~50 fps encoder plus an MLP projector doing 5x temporal downsampling to ~10 audio tokens/sec
  • Speech output is offloaded to an AR speech-token decoder plus a chunk-wise causal streaming flow-matching vocoder, with zero-shot timbre from a reference in the multimodal system prompt

Data construction pipeline (2.7M samples)

Four families. Speech interaction (~37%) includes the 260.8K InteractionSpeech full-duplex corpus, synthesized rather than inherited from turn-based data. Audio-visual (~40%) comes from JoyAI-VL, LiveCC and Streamo, realigned with Qwen3.5-297B-A17B. Agentic data (~13%) synthesizes user/cerebellum/back-brain trajectories with DeepSeek-V4-Pro. Robustness/negative data teach silence and speaker tracking.

  • 11.2K scene/topic seeds across 45 scenarios expanded into 8-18-turn dialogues capped at 96s of speaking time
  • Two annotated events: competitive interruption (remaining words kept as an unheard hidden continuation) and supportive backchannel (<= 8 Chinese characters / 6 English words, from a lexicon of 266 Chinese + 170 English expressions in 11 intent categories)
  • Only the user channel is rendered to audio; assistant turns are duration placeholders on an explicit timeline, so interruption timing is explicit supervision
  • Two-stage QC: rule-based gate then an LLM judge on naturalness, assistant coherence, interruption plausibility, backchannel plausibility

Evaluation setup and honesty controls

One checkpoint, no benchmark-specific tuning, byte-identical training system prompt. Full-Duplex-Bench v3 (all 100 scenarios) is run end to end through TTS and ASR so reported numbers include synthesis and recognition error; a back-brain-only text-driven row isolates the execution tier. SpokenQA + VoiceBench cover 2,052 utterances; WorldSense + Daily-Omni cover 4,369 MCQs graded by exact letter match with unextractable answers counted wrong, greedy decoding, 13,107 total inferences.

  • Back brain instantiated training-free via the Codex worker provider driven by GPT-5.6
  • Filler is defined over the 91 of 100 scenarios that take the turn without interrupting
  • A contract file was placed in the back brain's working directory so it received the same 'execute tools immediately' instruction baselines get
  • Scores across the three settings are declared non-commensurable and reported separately

Results and self-diagnosis

Gander wins interaction timing outright but trails on task accuracy end to end; the back-brain-only row shows the execution tier is not the bottleneck. Omni understanding is framed as a regression test against its own base model, and a modality ablation shows genuine fusion rather than single-stream dominance.

  • Full-Duplex-Bench v3: 100.0 take-turn, 8.0 interrupt (best), but Pass@1 0.400 — below the weakest baseline's 0.410; filler 51.6% is its worst interaction metric
  • Back-brain-only: ToolSel 0.934 beats every system including GPT-Realtime's 0.876; RespQual drops 0.740 -> 0.490 once the speech path is added
  • Spoken conversation: leads the full-duplex group on SpokenQA (75.60 / 59.30) but second on both VoiceBench subsets; the back brain was never invoked across all 2,052 samples
  • Omni understanding: 49.62 WorldSense (-6.08 vs MiniCPM-o 4.5) and 78.53 Daily-Omni (-1.67); the vision tower was frozen and is bit-for-bit unchanged

Key findings

  • On Full-Duplex-Bench v3, Gander (9B) takes the turn in 100.0% of scenarios and interrupts prematurely in only 8.0% of turns, versus 13.5% for GPT-Realtime and 47.9% for Ultravox v0.7 — but is last among full-duplex systems on task accuracy with Pass@1 0.400 vs 0.410 (weakest baseline) and 0.600 (strongest).
  • Removing the speech path lifts the same agent to ToolSel 0.934 (above GPT-Realtime's 0.876), Pass@1 0.520 and RespQual 0.740 — RespQual falls to 0.490 end to end, isolating the loss to routing plus the TTS/ASR channel rather than the executor.
  • Gander leads the full-duplex group on SpokenQA at 75.60 (Llama Questions) and 59.30 (Web Questions), +8.29 and +4.96 over Audio-Interaction, while placing second in-group on AlpacaEval (3.96) and SD-QA (46.84).
  • The back brain was never invoked across all 2,052 spoken-conversation samples, so Table 4 measures the front cerebellum alone — evidence the routing policy escalates only long-horizon tool work.
  • Omni understanding regresses asymmetrically from the MiniCPM-o 4.5 base: -6.08 points on WorldSense but only -1.67 on Daily-Omni, with the vision tower frozen and unchanged during training.
  • Modality ablation gives a fusion gain of +5.01 on WorldSense and +19.13 on Daily-Omni (overall +8.88), indicating real cross-modal integration.
  • Efficiency choices: ~16x visual token reduction via slice-wise SigLIP + resampler (vs ~4x in prior omni models) and 5x audio downsampling to ~10 tokens/sec, with a bounded 128-chunk (~2 minute) sliding context.

Notable quotes

Because the model reaches a decision once per window, proactive behavior arises naturally from the same mechanism and no external voice activity detection module is required to trigger responses.
Predicting this discrete control decision before any content is generated decouples the question of whether to speak from the question of what to say, which we find yields more stable full-duplex behavior than entangling the two in a single prediction step.
The back brain is a training free and general purpose task execution agent, instantiated by systems such as Codex or Claude Code.

Limitations

  • End-to-end task accuracy trails every Full-Duplex-Bench v3 baseline (Pass@1 0.400, RespQual 0.490), and the runs do not disentangle bad delegation decisions from ASR/TTS-induced error; the 51.6% filler rate is also the worst interaction metric in the table.
  • No dedicated benchmark exists for omni interaction agents, so the three evaluation settings are non-commensurable, several claims rest on subjective demos, and Brain-Cerebellum coordination itself is not measured by any benchmark.
  • The model has had no on-policy distillation or RL post-training, and Brain-Cerebellum communication currently relies only on ASR-derived text plus final video frames.

Open questions

  • Would a trainable back brain that receives the full multimodal input stream directly close the gap between the end-to-end and back-brain-only rows?
  • Can long-form response supervision and a wider accent distribution recover AlpacaEval and SD-QA without eroding the streaming turn-taking advantage?
  • Is the 6.08-point WorldSense regression an unavoidable cost of interaction-only post-training, or an artifact of a corpus dominated by irrelevant-visual-context negatives?
