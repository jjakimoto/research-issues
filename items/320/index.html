SkillRise: Agentic Reinforcement Learning for Cross-Task Skill Evolution

📰 Latest · 2026-07-30
Read full article →

Topic: Quantitative trading; machine learning for quant & trading; agentic coding techniques; and LLMs & multimodal LLMs — methods, papers, tools
Date: 2026-07-30

Source: arXiv (cs.LG) · 2026-07-29
Link: https://arxiv.org/abs/2607.26784

SkillRise lets an LLM agent learn and carry forward a single evolving 'skill document' across related tasks via decoupled credit assignment — beating GRPO/GiGPO on ALFWorld, WebShop, and ScienceWorld while running 4–6× cheaper than multi-stage skill pipelines. A clean take on agent memory as a learnable, transferable channel.

Executive summary

SkillRise is an end-to-end reinforcement-learning framework in which a single LLM policy alternates between solving a task and curating an evolving textual skill document that is handed to subsequent tasks. It uses decoupled credit assignment — current-task reward for solving, discounted downstream reward for curation — so the agent learns to write skills that actually help later. On ALFWorld, WebShop, and ScienceWorld it beats strong agentic-RL baselines (GRPO, GiGPO, RLOO) while avoiding the runtime overhead of multi-stage extract/retrieve/execute pipelines. It reframes agent memory as a single learnable information channel rather than an external subsystem.

The problem: agents that forget between tasks

Standard agentic RL treats each task as an independent episode, discarding acquired experience. Prior skill-learning methods either repeat a single task or bolt on complex multi-stage pipelines (separate extraction, retrieval, execution) that entangle credit assignment and inflate runtime.

  • Goal: transferable skills learned online, within one policy, across related tasks.
  • Related instances are grouped into progressively harder sequences via task-family metadata (simple→complex).

Method: one policy, one skill document, decoupled credit

A shared policy maintains a single textual skill document S_i, starting empty (S₀=∅). For each task it (1) solves using the current document, then (2) curates a revised document from the trajectory. Solving is credited with the current reward; curation is credited with a discounted return over subsequent tasks' rewards. Group-relative advantages are computed among trials sharing task group, sequence stage, and phase, optimized with a clipped objective.

  • The skill document is the sole information channel across tasks — its value is measured by downstream performance.
  • Decoupled credit assignment separates 'did I solve this' from 'did my notes help later'.
  • No external retrieval subsystem: skill writing/reading is inside the policy.

Results: better and cheaper

With a Qwen3-4B policy, SkillRise leads every benchmark and every baseline, including the strongest prior method GiGPO, and scales better with model size than GRPO/LaMer. It also matches or beats heavier pipelines at a fraction of their runtime.

  • Pass@1: ALFWorld 85.9, WebShop 84.4, ScienceWorld 54.6 — gains of +2.3 / +7.1 / +8.5 pts over GiGPO.
  • Scales better: +7.8 pts from 1.7B→4B on ALFWorld vs +4.7 (GRPO), +3.3 (LaMer).
  • RetroAgent / SkillRL need 6.0× / 4.3× SkillRise's runtime; SkillRise beats SkillRL by 12.5 pts.
  • Cross-task test-time scaling: 83.6% at K=2 → 87.5% at K=6.

Key findings

  • A single evolving skill document + decoupled credit assignment beats GRPO/GiGPO/RLOO across three agent benchmarks.
  • Best Pass@1: 85.9 / 84.4 / 54.6 on ALFWorld / WebShop / ScienceWorld.
  • SkillRise scales with model size better than baselines (+7.8 pts 1.7B→4B vs +4.7 for GRPO).
  • It matches heavier skill pipelines at 4–6× lower runtime and beats SkillRL by 12.5 pts.
  • Test-time scaling across tasks: 83.6% (K=2) → 87.5% (K=6).

Limitations

  • Assumes access to task-family metadata to construct sequences of related instances; automatic discovery in open-ended streams is unaddressed.
  • Experiments are limited to models up to 4B parameters due to compute.
  • Only three text-based benchmarks with verifiable outcome rewards; multimodal / real-world / less-verifiable tasks are untested.

Open questions

  • Can related-task sequences be discovered automatically from an open-ended task stream without metadata?
  • Does the single-document channel still scale at ≥14B parameters and with sparser rewards?
  • How does learned skill memory transfer to coding agents, where reusable skills are code/tool patterns?
