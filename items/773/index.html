Intern-S2-Preview: Scientific Agentic Foundation Model

📰 Latest · 2026-08-16
Read full article →

Topic: Quantitative trading; machine learning for quant & trading; agentic coding techniques; LLMs & multimodal LLMs; and autonomous research (autoresearch / AI-scientist) systems — methods, papers, tools
Date: 2026-08-16

Source: arXiv · 2026-08-13
Link: https://arxiv.org/abs/2608.13505

Shanghai AI Laboratory’s 397B scientific model combines multimodal pretraining, numerical time-series modules, executable agentic RL, and optional parametric memory. Its strongest contribution is the harness-agnostic training infrastructure, although the preview still trails frontier systems on several long-horizon agent benchmarks.

Executive summary

Intern-S2-Preview-397B is a large scientific foundation model trained for multimodal reasoning, time-series forecasting, tool interaction, coding, and iterative execution. Its agentic RL stack separates harnesses from executable tasks, captures exact rollout traces from black-box tools such as Claude Code and OpenHands, and grounds rewards in task-specific verifiers. Reported results are broad but mixed: the model leads many scientific benchmarks while remaining behind some frontier models on ResearchClawBench, TerminalBench, and SWE-Bench Pro.

Architecture and scientific specialization

The model adds a dedicated numerical forecasting branch rather than emitting long numerical sequences as text. A separate Memory Decoder trains a small domain memory against a frozen 397B backbone and dynamically blends its distribution with the backbone through a token-level router.

  • Intern-MemDec-4B raises the Biology-Instructions average from 56.92 to 60.32.
  • The memory extension improves several biology tasks without rewriting the frozen backbone, but individual tasks such as antibody-antigen and protein thermostability decline.
  • On SciTS, the model directly encodes numerical signals and predicts the required output horizon with 99% accuracy.

Harness × task agentic RL

A harness defines how an agent is instantiated and controlled; a task defines its environment, objective, and automatic verifier. This permits white-box loops and black-box runtimes—including Claude Code, OpenCode, OpenHands, OpenClaw, and Mini-SWE—to share one rollout and optimization stack.

  • The serving layer preserves exact token IDs, rollout probabilities, and MoE routing decisions while speaking native OpenAI and Anthropic protocols to each harness.
  • Semantic trajectories and verifier outcomes are stored separately from token-level traces, then joined by session and segment for training.
  • The public task mixture includes 59,136 SWE-smith tasks, 32,100 SWE-rebench-V2 tasks, 80,000 terminal tasks, and several other executable collections.

Verifier integrity and process credit

Complete sessions receive outcome rewards, while trainable assistant segments inherit session-level advantages. Deterministic process annotations can suppress positive credit for malformed tool calls, repetition, protocol violations, or abnormal termination without erasing the negative signal from failed sessions.

  • Gold patches, held-out tests, exact scoring identifiers, repository history, and remote references are removed from agent-visible environments.
  • Canonical tests are restored after the agent stops, preventing edits to visible tests from changing the grader.
  • Missing artifacts and infrastructure failures are separated from genuine task failure.

Performance and boundary

Intern-S2 is especially strong on scientific reasoning, biology, multimodal science, and multilingual software engineering. It does not establish a uniform frontier: GLM-5.2 and Claude Opus 4.8 lead several agentic benchmarks, and some reported scientific evaluations are internal.

  • ResearchClawBench: 18.44, below GLM-5.2 at 23.35 and Claude Opus 4.8 at 21.74.
  • SWE-Bench Pro: 61.56, below Claude Opus 4.8 at 69.20.
  • SciTS PHU01 F1 improves from 36.8 for Intern-S1-Pro to 66.9 for Intern-S2.
  • Zero-shot GIFT-Eval MASE is reported as 0.785.

Key findings

  • The harness × task abstraction enables one RL pipeline to train through heterogeneous black-box and white-box agent runtimes.
  • Memory Decoder improves the 21-task Biology-Instructions average by 3.40 points while leaving the 397B backbone frozen.
  • Intern-S2 leads the listed open models on multiple scientific benchmarks but is not the strongest system on every agentic benchmark.
  • The numerical forecasting branch beats the listed specialized time-series baselines on five of seven SciTS forecasting tasks.
  • The task-generation loop composes community skills through compatible environment-state paths and validates the environment, task, and verifier at every stage.

Notable quotes

Adding a new harness therefore requires a thin integration adapter rather than a new RL execution stack.
In particular, these tasks remain grounded in live environments rather than being reduced to static instruction–response pairs, so their rewards reflect program behavior, repository state, and task-specific execution outcomes.
Intern-S2-Preview remains a preview system; future work should improve reliability over longer scientific workflows, expand domain-specific memories and task environments, strengthen verifiers, and deepen integration with specialized scientific tools.

Limitations

  • Several scientific benchmarks are described as internal, limiting independent comparison and reproduction.
  • Models are evaluated through different harnesses and benchmark configurations, so the wide comparison table is not a single controlled inference setup.
  • The authors explicitly characterize the model as a preview whose long-workflow reliability and verifiers still need improvement.
  • A 397B backbone imposes substantial serving and training requirements.

Open questions

  • How much of the reported gain comes from the base model versus agentic RL, task synthesis, and the selected harness?
  • Will Memory Decoder retain its apparent specialization benefits across independently audited scientific domains?
  • Can the trace-aware RL infrastructure improve long-horizon research completion rates rather than only benchmark scores?
