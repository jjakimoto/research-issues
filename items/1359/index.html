TruthInsightBench: An Evidence-Grounded Benchmark for Automated Evaluation of Open-Ended Scientific Discovery Agents

📰 Latest · 2026-09-07 Full Article
Read full article →

Topic: Quantitative trading; machine learning for quant & trading; agentic coding techniques; LLMs & multimodal LLMs; and autonomous research (autoresearch / AI-scientist) systems — methods, papers, tools
Date: 2026-09-07

Source: arxiv · 2026-09-04
Link: https://arxiv.org/abs/2609.05079

A discovery-oriented (not reproduction-oriented) agent benchmark whose scoring is a frozen LLM judge applied to actually-executed analyses and artifacts, with deterministic aggregation and no per-instance human grading, and it finds that four mainstream coding agents on one frozen base model land in a statistically indistinguishable 58.4-60.3/100 plateau, failing precisely at controls, robustness, falsifiability and cross-dataset validation.

Executive summary

TruthInsightBench poses 40 blind discovery tasks derived from 40 peer-reviewed 2018-2024 studies across 10 scientific domains. An agent sees only a neutral research goal, frozen data, metadata, and a literature cutoff; the source study, its two reference findings, and all evaluation assets are hidden until after the run. A fixed LLM judge (GLM-5.1, W4A8-quantized, thinking disabled) scores each claimed discovery on 29 artifact-grounded items across six dimensions summing to 100, then de-duplicates semantically; aggregation into task and system scores is deterministic. Four coding agents on one frozen base model (DeepSeek-V4-Flash) score 58.40-60.27, with no pair separating at p<0.05 and all six pairs equivalent under a 4-point TOST margin.

Verifier grounding: frozen LLM judge + deterministic aggregation, not execution-graded

This is not an execution-grounded verifier in the unit-test sense; it is LLM-as-judge, but deliberately constrained. A single frozen judge model applies each of 29 predefined items to the analyses the agent actually executed and their result artifacts, at three levels (1 / 0.5 / 0). Only aggregation is deterministic. Execution grounding enters in two places: proposed-but-unexecuted tests earn zero, so the judge must locate the data, analysis and result; and the hidden evaluation assets include deterministic re-derivation scripts and tolerances used to recompute key quantities independently of the judge, which drive the deterministic-error penalty.

  • Judge is frozen and quantized explicitly to cut inference cost and remove chain-of-thought length variance from the 0/0.5/1 decisions.
  • Items avoid free-form preference judgments so scores can be regenerated automatically on new instances.
  • Semantic de-duplication is done by the judge within each system-task report only, never across systems.
  • No non-quantized / thinking-enabled judge-consistency audit was run; human-expert calibration and a second-judge sensitivity analysis are only planned.
  • Authors distinguish scoring variance from selection variance, which is unestimated under one run per cell.

Benchmark construction and information boundary

Visible: neutral goal, frozen data, metadata, and a per-task literature cutoff set strictly before the source study's publication. Hidden: source study, two reference findings, and evaluation assets. Sources: 34 Nature Communications, 2 Communications Physics, 1 Nature Physics, 1 npj Quantum Information, 2 Science Advances. Three admission conditions and six audited construction steps end with freezing both agent-visible materials and evaluation references.

  • Solvability verification: 2 re-derivations + 6 perturbation analyses per task = 8 construction-time verifications, 320 across the benchmark.
  • Blinding removes paper identity, conclusion direction, target values, the authors' analysis route, and evaluation thresholds, while preserving data semantics.
  • Only protocol-level blindness is claimed; pretraining contamination cannot be excluded.
  • Modalities: tabular/time-series, structured arrays, networks, molecular or particle coordinates, scientific images.

Scoring rubric and aggregation

Six dimensions, 100 points: evidence auditability 45 (8 items), robustness 15 (5), control testing 15 (5), cross-dataset generalization 10 (4), novelty 10 (2), falsifiability 5 (5). Task score R = clamp(0.60*S1 + 0.20*S2 + B_yield + B_target - P_false, 0, 100), where S1/S2 are the top two semantically distinct discovery groups. B_target is deliberately small and non-gating so the answer-key logic of reproduction benchmarks is not reintroduced. P_false deducts 5 per claim whose direction execution or re-derivation contradicts.

  • Coefficients were fixed before evaluation; an ablation removing both bonuses reproduces the same ordering.
  • Null results, counterexamples, method artifacts and scope boundaries score on the same footing as positive regularities.
  • Matching the source conclusion without a traceable, robust, controlled evidence chain is explicitly not credited.

Experimental protocol and the discovery-execution gap

Claude Code v2.1.220, OpenScience v2.0.1, Codex CLI v0.149.0, DeepSeek Harness v0.1.0rc7, all on the same frozen base model with thinking disabled, to isolate scaffold effects. One run per system-task: 160 evaluation units, 724 reported discoveries (630 after de-duplication), roughly 2.1e4 item-level judgments. All systems produce comparable breadth (3.65-4.30 de-duplicated discoveries per task) but top-two evidence quality reaches only 43.33-44.58 of 80.

  • Dimension rates split into a strong pair (evidence auditability 78-81%, novelty 83-87%) worth 55 points and a weak quartet (control testing 11-16%, robustness 9-14%, falsifiability 29-33%, cross-dataset generalization 0.00-0.41%) worth 45 points.
  • Cross-dataset generalization near-zero is attributed to a benchmark-side floor, a genuine agent-side discipline gap, and a single-phase operational limit.
  • Per-task scores span 36.2-72.9 and per-task cross-system spreads reach 25.5 points, so the plateau reflects compensating wins/losses, not an undiscriminating instrument.
  • Wilcoxon signed-rank: smallest p = 0.118; TOST equivalence at 4 points holds for all six pairs.

Key findings

  • Four coding agents on one frozen base model cluster in 58.40-60.27/100 (spread 1.87); no pair separates (smallest Wilcoxon p = 0.118) and all six pairs are statistically equivalent within 4 points by TOST.
  • Verification is LLM-as-judge, not execution-graded: a single frozen, quantized, thinking-disabled GLM-5.1 judge scores 29 items at 1/0.5/0; only aggregation is deterministic. Execution grounding comes from requiring locatable executed analyses plus hidden deterministic re-derivation scripts behind the false-claim penalty.
  • The 38-40 point strong-weak dimension gap: evidence auditability 78-81% and novelty 83-87%, versus control testing 11-16%, robustness 9-14%, falsifiability 29-33%, cross-dataset generalization 0.00-0.41%.
  • Breadth without depth: 3.65-4.30 de-duplicated discoveries per task, but top-two evidence quality is only 43.33-44.58 of 80 (about 55%).
  • Construction cost: 40 tasks from 40 peer-reviewed studies, each verified with 8 construction-time checks = 320 verifications.
  • Evaluation scale: 160 system-task units, 724 reported (630 de-duplicated) discoveries, roughly 2.1e4 item-level judgments; exactly one frozen run per cell.
  • Task difficulty and cross-system disagreement are weakly negatively correlated (Pearson r = -0.31, p = 0.049), i.e. harder tasks separate systems more.

Notable quotes

Scoring is automated and artifact-grounded: a single frozen LLM judge applies each item to the analyses the agent actually executed and to their result artifacts, and only the subsequent aggregation is deterministic, so an evaluation reruns on a new agent version with no per-instance human grading.
All four coding agents cluster in a narrow band of 58.4–60.3 out of 100 (a spread of only 1.87 points), and their mean confidence intervals overlap.
Cross-dataset generalization is near zero for three distinct reasons.
The bottleneck for current AI-scientist systems is therefore scientific judgment rather than execution.

Limitations

  • One frozen run per system-task cell: selection variance is unestimated, so the pairwise ordering is not reliable; a multi-seed protocol is only planned.
  • The judge is a single frozen, quantized, thinking-disabled LLM with no human-expert calibration and no second-judge sensitivity analysis yet.
  • Tasks are single-phase, dry-lab, and drawn from open-data papers, so cross-dataset generalization is structurally under-measured; only protocol-level blindness is claimed.

Open questions

  • Do the same execution-vs-discovery gaps persist with frontier base models rather than the mid-capability DeepSeek-V4-Flash, and would scaffold differences separate then?
  • Would a two-phase protocol that releases validation data only after a discovery and its pre-specified criteria are recorded actually recover non-zero cross-dataset generalization?
  • How closely does the frozen quantized judge track expert human grading, and is the automated score stable enough to serve as the feedback signal in a recursive research-improvement loop?
